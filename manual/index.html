User guide / Mac & Windows

DanpaSync の使い方

動画を用意するところから、曲に合わせて映像を出すまで。Mac 版と Windows 版に共通する基本操作を紹介します。画面の名称や配置は、バージョンによって多少異なる場合があります。

CONTENTSはじめに署名を作る署名フォルダを選ぶ曲を認識して映す同じ音声の映像を切り替える困ったとき
01 / Get ready

はじめに

DanpaSync は、流れている音を登録済みの動画の音声と照合し、対応する映像を曲の位置と速度に合わせて再生するアプリです。

用意するもの

  • 音声が入った動画：認識したい曲の映像を用意します。署名は動画の音声から作るため、音声のない動画では署名を作れません。
  • 音声入力：会場の音を取り込むマイクやオーディオインターフェースなど。
  • 映像の出力先：必要に応じて外部ディスプレイなどを接続します。

署名とは？ 曲を聞き分けるために動画の音声から作るデータです。署名を作る前の曲は認識できません。

02 / Create signatures

動画から署名を作る

  1. メイン画面の「署名を作る」欄から、動画から署名を作る画面を開きます。
  2. 動画ファイルまたは動画が入ったフォルダを選ぶか、作成画面にドラッグ＆ドロップします。複数の動画を追加できます。
  3. 「署名フォルダ（保存先）」を確認します。必要に応じて別のフォルダを選びます。
  4. 「署名を作る」を押し、解析が終わるまで待ちます。画面に案内が出たときは、動画やフォルダへのアクセスを許可してください。
  5. 完了後、署名フォルダの曲数と「動画のリンク」を確認します。

動画と署名の置き場所は別です。 署名の作成後も、元の動画は再生に必要です。元動画はそのまま残してください。

ボタン名は Mac では「動画から署名を作る…」、Windows では「署名を作る…」など、版によって異なります。

03 / Signature folders

署名フォルダを選ぶ

署名フォルダは、作成した署名と曲の管理情報を保存する場所です。元の動画が入ったフォルダとは役割が異なります。

  1. 新しく署名を作るときは、作成画面の「署名フォルダ（保存先）」を確認・選択します。
  2. すでに作成済みの署名を使うときは、メイン画面の「署名フォルダ」から既存の署名フォルダを追加します。
  3. 追加後、曲数や動画のリンク状態を確認します。フォルダが見つからない場合は、外付けドライブの接続やフォルダへのアクセス許可を確認してください。

設定を変更できないときは、いったん認識や署名作成を停止してから操作してください。フォルダの選択を解除しても、署名ファイルそのものを削除する操作ではありません。

04 / Listen & output

曲を認識して映像を出す

  1. 入力欄で会場の音を取り込む機器を選び、入力メーターが動くことを確認します。
  2. 「認識開始」を押し、登録した曲を流します。認識の状態と曲名を確認してください。
  3. 認識された曲に対応する動画が見つかれば、映像の位置と速度が曲に追従します。
  4. 「出力ウィンドウ」を開き、必要に応じて出力先の画面や全画面表示を選びます。

Mac の App Store 版と Windows 版では、出力ウィンドウで映像を表示できます。Windows 版は Spout で対応する VJ ソフトへ映像を送ることもできます。

05 / Choose a video

同じ音声の映像を切り替える

同じ曲の音声に対応する映像が複数ある場合、曲を認識したあとで使いたい映像を選べます。たとえば、同じ音声を使った別の映像を切り替えたいときに使います。

  1. あらかじめ、それぞれの動画を登録して署名を作ります。
  2. 認識を開始し、対象の曲が確定するまで待ちます。
  3. 認識画面の「同じ音声の映像」に候補が表示されたら、使いたい映像を選びます。版によっては一覧のボタン、または選択欄から選びます。
  4. 選んだ映像が優先されます。優先を解除したいときは、「優先を解除」を使います。

同じ音声かどうかは、曲名だけを基準に判断するわけではありません。候補が出ないときは、両方の動画の署名とリンクを確認してください。別の音声として扱いたい組は、画面の「束ねない」で分けることもできます。

曲が流れる前に選ぶ

署名フォルダの「同じ音声の版」や「版の一覧…」から、まとまった映像を確認し、曲ごとに優先する映像や「束ねない」を設定できる版もあります。

表示場所や利用できる操作は、アプリのバージョンや認識状態によって異なる場合があります。

06 / Troubleshooting

困ったとき

署名が作れない

動画に音声が入っているか、動画や保存先のフォルダを開けるか確認します。画面にエラーが出た場合は、その内容も確認してください。

曲が認識されない

対象曲の署名が登録されているか、入力機器が正しいか、入力メーターが動いているかを確認します。音量が極端に小さい、または歪んでいる場合は入力レベルを調整してください。

曲は認識するが映像が出ない

「動画のリンク」で元動画が見つかるか確認します。動画を移動した場合は、画面の案内に従ってリンクを見直してください。出力ウィンドウや出力先の画面も確認します。
